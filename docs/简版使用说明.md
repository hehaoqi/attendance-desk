# 工人考勤管理系统简版使用说明

适用对象：日常只需要录工人、记考勤、算工资、记发薪的使用者。

## 1. 启动软件

1. 双击 `工人考勤管理系统.exe`。
2. 看到登录页后输入账号。

默认账号：

- 用户名：admin
- 密码：admin123

## 2. 日常操作顺序

建议每天按这个顺序操作：

1. 工人管理
2. 考勤录入
3. 工资核算
4. 发薪登记

## 3. 工人管理

1. 进入“工人管理”页面。
2. 点击“新增工人”。
3. 填写姓名、工种、级别、日薪、加班时薪。
4. 点击保存。

说明：

- 之后工资计算会直接用这里的日薪和加班时薪。
- 停用离职人员时，把状态改为非在职即可。

## 4. 考勤录入

1. 进入“考勤”页面。
2. 选择日期。
3. 给每位工人填写当天状态：
   - present：正常出勤
   - half_day：半天
   - leave：请假
   - absent：缺勤
4. 如有加班，填写加班小时数。
5. 点击保存。

## 5. 工资核算

1. 进入“工资”页面。
2. 选择年份和月份。
3. 点击“计算”。
4. 核对每位工人的工资。

当前计算规则：

- 正常工资 = 日薪 × (正常天数 + 半天数 × 0.5)
- 加班工资 = 加班小时 × 加班时薪
- 总工资 = 正常工资 + 加班工资

## 6. 发薪登记

1. 进入“发薪”页面。
2. 选择工人。
3. 填写发薪日期、金额、方式、备注。
4. 点击保存。

建议：每次发薪都登记，方便后续核对“应发/已发/未发”。

## 7. 出问题如何处理

1. 菜单栏点击“文件 -> 打开日志目录”。
2. 找到以下文件：
   - app.log
   - error.log
3. 把这两个文件发给维护人员。

Windows 默认日志位置：

- `%APPDATA%\\attendance-system\\logs\\app.log`
- `%APPDATA%\\attendance-system\\logs\\error.log`

## 8. 数据备份建议

建议每周备份一次以下目录：

- `%APPDATA%\\attendance-system\\`

这个目录内包含数据库和日志，拷贝后可用于恢复。
